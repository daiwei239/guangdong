# Visual Frontend

这是单独的 React + Vite + TypeScript 前端，用于异构资源匹配过程可视化。

当前页面按 5 个阶段逐步展示：

1. 异构资源采集与统一描述
2. 异构资源 DAG 构建
3. 多模式任务需求表达
4. 候选资源子网搜索 + GNN 匹配
5. 结果排序与验证输出

交互方式：

- 初始不直接展示全部结果。
- 点击“显示下一步”，每次只新增一个阶段。
- 点击已出现的步骤按钮，可以回看该步骤的大画布。
- 第 5 步出现后，底部才展示最终输出。

运行：

```bash
cd visual_frontend
npm install
npm run dev
```

默认地址：

```text
http://127.0.0.1:5173
```
